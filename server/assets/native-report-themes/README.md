# 原生学习报告主题资源

五套插画来自本任务内置图片生成工具产物，经用户确认后用于学习报告。原PNG保持不变；纸色取自插画边角，HTML用透明度、混合与底缘渐隐融合。每赛道当前一张图，不代表同赛道多图图库。

月蓝仍用浅色纸面，保留插画融合和正文对比度。CSS中的纹样只占页边或独立标题行，不覆盖正文。关闭JavaScript仍能完整阅读，不加载外部字体或图片。

服务端通过模块相对URL读取资源，不依赖工作目录。Docker现有COPY包含本目录，运行入口为tsx源文件；不得只打包TypeScript而遗漏本目录。每次导出仅嵌入被选中的一张PNG，不将五张全部塞入报告。资源缺失时明确失败，不上传无插画的半成品；原始学习JSON不受影响。
