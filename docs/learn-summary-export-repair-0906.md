## 改动与双向追链

- 两必填栏统一拒绝空白、单字及旧占位文本。只有精确同源且全部分片具备正文才自动恢复，缺片拒绝；parser/增量合并取消这两栏600字静默截断。
- 提案写入与正式批准共用完整新批次判断：来源一致、批次不同、时间更新、全分片证据齐全；请求快照相同不等于输出相同。旧正式版归档，完整重学不混合旧镜头；approved 已提交后 proposal 同步失败可幂等重试。
- 原生逐集“删除此卡”和“放行重学”共用生命周期锁。两份原字节先归档、回读一致后 CAS 删除 approved/proposal；支持部分失败重试、仅正式卡存在。分片与模型证据不删除。
- 仅重新整形参数贯穿 UI、API、任务、计划、执行器和 runner。绑定原任务、用户、来源、集号和读片参数；等待旧 worker 退出，写入前检查取消。缺少完整可信 JSON 明确失败，不走新读片模型。
- 新模型分析校验拒绝超长标题、错误五维对象和有证据却缺分析的新格式；历史无标题格式兼容。报告缺五维分析时展示真实完整标签并明确标识，不再套句伪装。
- 广告账目由原始 non_story_ad 和源显式区间确定性组装；源 JSON 不变，不采信模型虚构区间。
- 自动系列聚合取消。保留逐集整理与待审，不额外产生系列模板。
