# 独立小说工作室 · 管理者测试

新增 `/novel-adaptation`，不挂载 OmniCanvas、不读写唯一漫剧云草稿。底本导入或原创新方向 → 顾问建议及真实模板库推荐 → 可编辑提案 → 分章小说 → 用户确认 → 各2–3集的单模板/组合模板候选。正式计价未定，服务端仅允许 admin/supervisor；仍会产生上游模型成本，每次提交显式确认。

模板选择最多5个，每个可指定组合分工。顾问推荐3–5个不同库内模板并排除用户已选，不足时只给真实可用数量。正文同色，变化按场景/人物/妆容/灯光/氛围/对白分类，以句子差异展示；不是语义质量判分。闪烁在展示或点击分类后短暂发生，可关闭，遵循 reduced-motion。比较必须来自相同轮次、底本、方向、大纲、已确认小说及集数。场次按模型返回key排列；无法保证不同模板的同编号场次语义完全一致，需用户审阅。

## 调用链与邻接检查
- App/Navbar → NovelAdaptation → novelWorkspace（独立本机草稿、CAS写入、封存旧轮） → novelWorkspaceRouter（管理者授权/请求schema） → novelWorkspaceTest（DB操作占位、模板解析、完整原始与规范结果） → 现有callNovelStage（GLM及拥塞fallback）。
- 不走expandManhuaWriterPack、不改已有积分定价或生产草稿API。每次UUID占位，同ID不同输入拒绝；运行/失败不自动重提；成功同ID读取已存结果。刷新后仅手动查询回执，不自动生成。用户主动不同ID仍可产生新上游成本。
- 输入和完整模型汇总响应保存到本轮jobs记录；收到真实流字节才续写活动时间；保存失败停止，不伪造心跳。新增动作从通用DELETE清理排除，避免证据丢失。跨进程中断且心跳失联的running记录改为failed但保留证据，没有自动接续或自动重做。
- 复用SSE增加可选持久化钩子；没传钩子的知识卡/其他旧调用行为保持不变。知识卡完整性与旧小说链定向回归已跑。
- 返回结果替换当前编辑前保存本机快照；重新开始先完整封存旧轮再建空稿。配额不足、损坏草稿或另一页更新均拦截写入。
