# 视频号本机采集运维硬规则

## 搜索标签与内存

- 用户硬上限：同一微信视频号窗口的标签总数不得超过 3 个。
- 当前实现采用更严格上限：1 个推荐页标签 + 1 个复用搜索标签，总数最多 2 个。
- 搜索词轮换必须复用唯一搜索标签，禁止每个搜索词新建标签。
- `openedTabs` 只是跨进程保护状态，不能代替真实窗口验真；进程重启后如无法确认真实标签数，暂停新增搜索标签，先人工检查并收敛窗口。
- 恢复采集前必须确认：窗口标签不超过上限、没有图片/贴图查看器、没有评论面板、没有赞和收藏页。

## 一小时验收

- 唯一可信产量是 Fly `persisted=true` 且 `newlyQualifiedPersisted=true` 的正式记录。
- 16:30 起的一小时验收目标为真实去重新增 50–80 条；低于 50 条自动停采并输出失败漏斗和交接文档。
- 禁止用本机 `scanned` 或 `qualified`、重复 observationId、假评论、假时长凑数。
- 采集期间只运行一个采集进程，禁止并行编译和测试，`modelCalls=0`。
