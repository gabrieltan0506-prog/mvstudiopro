## 跨层双向追链

正向：工作台标签/所选资产/后期当前工具→页面当前可见工作区→项目context→严格schema→普通顾问服务端prompt，以及Live初始上下文/inspect；上下文变化使旧操作候选来源失效。反向：Live inspect读取当前ref中的context，字段在长正文前；服务端prompt的activeStudio来自同一schema和真实选择回调，工具选择不修改制作阶段或作品正文。

后期参数保持挂载，仅隐藏非当前工具；原提交、费用确认、任务恢复、下载和结果采用入口不变。字幕源回调仅控制原片预览。小说语音上下文加入当前四步页面，方向已有内容时不再提示未填写。
