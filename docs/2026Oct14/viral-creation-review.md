# 爆款创作与图文知识卡片：本批审查记录

## 范围与变更

创作页仅保留爆款创作、图文知识卡片，数据分析留在趋势报表。新增双平台、多形式独立稿件；五份用户资料转为六种内容结构与七类创作方法。旧候选选题刷新后不再恢复，已生成正文、失败份和原任务编号保留。

主页面采用横向三步导航、同区点数确认、可编辑选题卡片。移除旧 Skill 推荐面板、旧自定义选题/海报入口、重复输出类型及创作页下方的分析窗口。知识卡片保留上传、提炼、分页、生成和下载链路。

## 方法迁移

- `hook-solution-cta` 的人群、问题、正文兑现与承接价值，编入方法库及创作包。撤回固定开场句、三字评论钩、强制三秒与留答案换咨询。
- `cover-stop-scroll` 的少字主标、具体视觉焦点、角色场景一致性，接入结构化封面方案与原图片消费者；不采用无依据效果数字或默认时尚人设。
- 来源校验、承诺原文对应、空图文页与空分镜拒绝，成为运行时校验。特殊赛道模板不再作为新创作页通用必选项，旧方法文件仍供原路径使用。
- 未取得技能使用量统计，移除依据是当前页面用途、重复与规则冲突，不声称已证实某技能从未使用。

## 双向追链

入口 → 背景及平台/形式选择 → 初选服务读取 Growth → GLM 生成 → 选题 schema → 独立平台/形式 ID → 原异步扩写任务 → 创作包审查 → jobs / 本机恢复 → 正文、分镜、视觉方案 → 原快照与图片入口。

反向：图片读取 DB 快照中的目标平台、方案视觉与 viralCreation 标记；标记由审查通过的扩写蓝图产生。正文恢复来自原 job ID 和本机已保存蓝图，不从展示卡片伪造生产数据。封面固定 Sunburst，官方失败仅同模型 EvoLink 备用，未知回执沿原结算链处理。

## 验证及边界

首轮隔离 65 项中 64 通过，唯一失败 VC-05；修正后的受影响路径与新增 Sunburst 路由测试 20/20 通过。真实 Growth 只读探针返回双平台非空相关摘要，明确发布时间与采集时间之别。最新类型检查 exit 0，Vite 前端构建通过；存在原项目大 chunk 提示。

隔离上游使用虚构结果、禁止网络调用，不等于真实付费模型生产验收。UI 截图采用实际新组件及虚构选题，不等于正式登录页面验收。本批未发起付费文本、图片或视频。原扣点/退款与队列基础设施未重构，后台重入的所有极端失败情形未做生产演练。合并前必须重新核对真实任务、部署与 CI。

最终补验：工作机自动停止丢失临时目录，恢复过程中首轮漏装最新 selection 文件，18 通过 / 1 失败；完整恢复当前改动后，同组定向回归 exit 0。此环境修复未改业务断言。
