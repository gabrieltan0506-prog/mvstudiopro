## 用户合同

- 注册账号的普通文件免费：上海自然日，每账号及同来源 IP 各最多 3 个原文件，两个条件同时执行；单文件不超过 3,000,000 字节。相同原件的检查、重复确认和不同格式使用 SHA 去重。
- 超额提示固定为“今日免费转换已达上限，如需继续使用，请充值。”超尺寸不占名额；失败、取消、拒绝或撤销检查释放未消耗的预留名额。成功原件保留当日消耗。
- 免费任务由网站 app 的独立持久串行队列处理，显示前方不同的其他用户人数，不暴露身份。付费任务在既有 rig 独立队列执行，仍遵守实际资源互斥，不改学习并发门禁。
- 付费每次检查报价、确认、幂等扣积分；失败或取消按原扣款来源退款。充值不意味着以后免费或永久插队。
- 已接通 PDF→Word/TXT、HTML→PDF、EPUB→PDF、UTF-8 TXT→Word、静态图片→PNG/JPEG/WebP/TIFF/AVIF。EPUB→TXT 未提供。
- PDF→Word 是可编辑文字版，按原页分隔，不复刻复杂版式/图片/表格。扫描识别会标注低置信度文字，仍需对照原件校对。

## 生产与消费链

`HomeFileConversion` → 登录保护的 `fileConversion` 路由 → 本人私有 GCS 对象及实际 metadata/字节/SHA/generation 校验 → 专用持久队列与两维额度槽 → app/rig 同角色执行器 → 永久结果回执与私有输出 → 本人记录/下载。

任务 ID 和扣费键稳定；免费预约与入队使用同一 SQL；多实例每车道只有一个 running；30 秒成功持久化心跳续期，连续十分钟失联才恢复同一永久结果或失败退款，不自动重做。结果/免费消耗在同一 SQL 终结，停机门禁不再领取新任务。跨日确认按确认当天和当前来源 IP 重新预约。

来源 IP 仅在 Fly 信任平台 `Fly-Client-IP`，忽略 XFF；前端此组 API 直达同站 API 主机。仅持久化按日 HMAC，不保存明文 IP。生产密钥只由服务端读取，未复制到本地。

HTML 禁脚本，阻断远程/本机资源；图片必须实际解码成功。展开折叠正文，解除滚动裁切，宽表采用横向排版。EPUB 按 spine 保留章节与图片，流式计量实际解压大小，拒绝加密/坏包；不沿用剥图回退。

## 离线 OCR 与镜像

使用 `rapidocr-onnxruntime==1.4.4`，13 项 Python 依赖全部固定，3 个识别模型随包内置。安装到独立 `/opt/file-conversion-ocr`，不覆盖系统 Python。锁定依赖的 COPY/安装缓存层在业务 COPY、CACHEBUST 之前，在既有 Blender 安装之后；不改变现有 Blender 安装步骤。

运行只读包内模型，缺失即失败；不请求时 pip、不下载模型、不调用外部 OCR 服务。关闭 ONNX telemetry。每个 OCR 进程限制 2 个计算线程。开发机安装约 261 MiB，其中模型约 16 MiB；不同平台镜像精确增量未实测。

## 真实原文件开发结果

均经用户确认，仅本地文件 I/O 适配调用正式转换器；无生产上传、无扣积分、无付费模型。原文件不变。

| 原文件类型 | 实际输入 | 当前输出 | 本地耗时 | 内容检查 |
|---|---:|---|---:|---|
| 中文 HTML，90 张内嵌图 | 10,155,223 字节 | PDF 33 页，12,739,586 字节 | 6.247 秒 | 1,752 个长正文段均匹配；宽表/分页实图已检查 |
| 中文扫描信息图 PDF | 10,576,824 字节，4 页 | DOCX 13,042 字节；TXT 9,396 字节 | OCR+DOCX 98.397 秒 | 对照 4 页原图；主体文字可读，专名/错字/多栏顺序/微缩示例仍需校对 |
| 中文 EPUB | 1,948,984 字节，28 章、37 图 | PDF 241 页，8,329,720 字节 | 3.007 秒 | 4,027 个长正文段均匹配；正文实图已检查 |

TXT 复用该次 OCR，额外导出 0.091 秒，不是独立全流程耗时。机器为 Apple M1/16 GiB，不等于 Fly performance 4 vCPU/8 GiB 实测。平均 OCR 置信度不等于全文正确。
