## 实现与双向追链

- 初始化只保留同对象、合法且距离到期超过五分钟的 GCS V4 地址；缺失、畸形、未来时间及过期地址继续原鉴权恢复。生成预检不消费此跳过判据。
- 共享图片错误链先查真实本机字节；缺失、读取失败或本机字节解码失败，再对可还原 GCS 身份做一次有界续签。只合并在途同对象请求，不永久缓存签名。其他外链与本机指针不猜云身份。
- 续签只修改该 img 的显示地址；新地址须仍为同一 GCS 对象。并发错误不重复发起、换图/卸载后迟到结果不覆盖、失败只通知一次。原图/草稿/生成输入不变。
- 两个自定义参考图放大入口带独立 assetRefId；预览与裁剪按当前同 ID 参考取现址。同名不同图按 ID 区分，既有 sheetPreview.id 仍只代表画布节点，不暴露错误的节点编辑按钮。

正向：真实 image job → 同 ID 新参考及 gcsUri → 初始化保留有效签名 → 共享图片 → 本机优先／同对象有界续签 → 非空解码。放大和裁剪始终从同一参考身份取址。

反向：显示 img 的同对象 HTTPS 或本机 blob → 原 src 的存储身份／同源本机记录 → 当前参考 ID → 原任务输出对象；续签不创建任务、不改 canonical、不落新缓存、不改变旧产物归属。另一入口、旧草稿、换源、失败及重跑生成仍维持各自原契约。
