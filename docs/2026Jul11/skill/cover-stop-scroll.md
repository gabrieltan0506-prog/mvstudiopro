# 封面停滑与信息层级 Skill

## 用途
专管「第一眼」竖版信息流封面。出图 Prompt **必须**遵守。宁可少字、姿势过火，也不要「正襟危坐要开课」。

## 高赞样本密度课（mk/mk1/mk2/mk3 · 医学科普为何高赞）
样本：`~/Downloads/2026Jul13/mk.mp4`（选题包·藏>赞工具帖）· `mk1.mp4`（MSD+3D·赞藏五万级）· `mk2.mp4`（搜索场菜单）· `mk3.mp4`（漫画细胞）。  
详摘：`docs/2026Jul13/mk-medical-highlights.md`。

**医学/急救/机制向封面高赞原因（生成时强制对齐 1 条壳）：**
1. **大数字选题包（mk）**：主视觉「100个」最大字 + 类目「医学科普类」+ 结果承诺「谁写谁火/选一个就行」；纸纹底+黄/红条提亮；角标「收藏点赞码住」。**藏≥赞**因为是可存工具，不是情怀。  
2. **硬核网站种草（mk1）**：封面/前3秒必须有**屏幕证据**（MSD 大众版页顶「专业的|大众版」、或 3D 动画特写）+ 结果钉「瞬间了解任何疾病 / 3D讲清发病原理」——不是空喊「权威网站」。  
3. **反课堂钩子（mk2/mk3）**：杀伤句择一——「把医学知识当八卦讲」「麻醉=时空穿越」「好员工如何黑化」「不看显微镜切片看黑帮片」；**禁止**「××病定义与分型」论文封面。  
4. **少字提亮**：类目条（医学科普类/急救知识类）+ 大数字或结果钉 ≤2 行；禁止病名恐吓墙、白大褂证件照默认脸。  
5. **审核友好**：钩子可以野，画面不堆血肉/手术台；资源对照用公开站截图标意即可。

## 高赞样本密度课（x1 搜索瀑布 + x2/x3 清单视频）
样本：蓝海词 **「親子旅遊清單」** 搜索瀑布（`x1.jpg`）；`x2.mp4` 出行妙招（藏>赞）；`x3.mp4` 带娃 12 神器（藏≈6万）。  
详摘：`docs/2026Jul13/x1-x2-x3-highlights.md` · 抽帧 `~/Downloads/2026Jul13/x{2,3}-frames-dense/`。

**清单/攻略向封面（优先于「正装大片脸」）：**
1. **主句杀伤词**（择 1–2）：必備 / 清單 / 帶娃 / 保姆級 / 不踩雷 / 救命 / 建議收藏 / 懶人必看 / 被問爆 / 無廣  
2. **证据画面**：摊开行李箱、flat lay 神器墙、备忘录/清单怼镜头、机舱或酒店真场景、手持神器特写——**禁止**空书房讲课半身像当默认  
3. **大数字 + 结果钉**：如「12 个」「一口气分享」+「全程安安静静 / 两三套玩 10 天 / 省钱省事」  
4. **少字大字**：黄/白描边、对比强；总共 ≤2 行可见文案；关键字 2–6 字提亮  
5. **反推荐可香**：「别买这些」「后悔带的」比空好物墙更像真话  

## 硬约束（文案层·高点击短钩）
1. 屏上主句 **`coverHeadline` 最多 13 字**（含标点；超则精简），只说一个**反差/反常识/猎奇缺口**；气质对标「天天打游戏怎么考上北大」「每天十碗饭反而瘦十斤」。**禁止**正确无聊、论文式副标整屏印上。
2. **提亮规则**：主句里只允许 **2–6 个关键字**用鲜明强调色（黄/亮蓝择一）标出；其余字用白/浅色大字即可。精简是为了停滑与点击，不是恐吓砍字。
3. 副标可选，**≤12 字**一行；总共可见文案 **≤2 行**。无副标往往更好。
4. **禁止百科封面**：书名墙、多图标+多辅标栏、说明书信息图、履历小字。
5. 正例气质（调适后，勿照抄人脸）：小红书清单作者那种——**大字少、关键字亮色、证据画面**；再叠人设道具。
6. 屏内字一律**中国大陆简体中文**。

## 硬约束（有人物·表情姿势·禁止坐姿复读）
信息流不会点「坐着上课」的正经半身像。有人物时：

1. **强烈禁止默认**：正面端坐办公桌/咖啡桌、双手搭桌、端杯正视、证件照微笑、冷脸讲课、对称「老师开场」。
2. **每条封面必须换姿势**（同批六条不得六张都坐着）。为**黄金三秒停滑与完播**，表情姿势宜**多元且可适度夸张**——帅气运动瞬间、登顶哲理瞬间、喜剧错愕瞬间都合格，按选题气质轮换：  
   - **表情（多元）**：瞪大眼不信、错愕、坏笑、大笑、陶醉、专注杀气、登顶释然、发球前凝神、突然醒悟、自嘲捂脸、假装正经……  
   - **动态·生活/喜剧（可夸张）**：跳起来、差点摔倒/失衡、探身递东西怼镜头、回头甩头、歪头半遮脸、夸张摊手……  
   - **动态·帅气运动（高度推荐轮换）**：网球发球展体、挥拍随球、爬山登顶举手/拄杖远眺、游泳出水、冲刺起步、击球重心转换……  
   - **动态·清单工具向（x1/x3）**：俯拍装箱、手持清单怼镜头、摊开神器墙、指着结果钉字幕——**优先于**冷脸正装半身像  
3. **题材融合**：同一封面/选题可同时服务「心肺/运动负荷」与「人生往高处走」——画面用发球/登顶等真动作，文案钩子可心肺机制 × 人生哲理对照（勿变成干讲课）。  
4. 允许「递物怼镜头」「侧身失衡」「发球定格」等强构图；**不允许**六条都是「坐姿+看镜头」，也**不允许**六条都挤同一搞笑表情，更**不允许**六条全是冷脸大片。  
5. 时装质感可留，但**不得**用「挺拔从容冷淡大片」压死表情与动态；运动场景服装跟场域走。  
6. 锁脸时：同一人，表情姿势仍须丰富；为完播可写「比日常略夸张一档」的微表情，忌尴尬演技说明书。

## 硬约束（场景服饰·防穿帮）
**动作决定穿什么**——这是出图最高优先级之一，压过「随便套件大片外套」：
1. 网球/挥拍 → 网球运动装（短袖或网球裙裤 + 球鞋 + 球拍）；**禁止长大衣、厚外套、正装西服边发球**。
2. 游泳/出水 → 泳装或刚披上的防水运动外套；禁止全套正装湿身。
3. 爬山/登顶 → 冲锋衣/功能外套/登山鞋；可有风感，但仍是户外装备。
4. 书房/厅堂访谈 → 才可用西装、丝绸衬衫、克制外套。
5. 带娃出行/装箱清单 → 休闲出行装或家居装箱 POV；禁止正装讲课服硬套进行李箱画面。
6. 锁脸时：脸必须是参考人；**衣着仍跟本条场景**，不可为保大片感硬套冲突服装。

## 小红书作者风 → 为我所用（调适，非照搬）
- **要学**：少字大标题、关键字亮色、干净留白、脸可读、可选 **最多 1 个**极小视觉证据点（勿图标墙）；清单向学 **flat lay / 行李箱 / 备忘录怼镜**。
- **要改**：把「正坐讲课脸」换成**有戏的表情/动态**（含帅气运动，不限搞笑）；道具跟人设（典籍、运动、爵士、旅行、带娃神器）走，不要默认医疗白大褂/手术帽，除非人设明确需要且审核友好。
- **不要学**：病名大字恐吓、临床特写堆叠、满屏说明书。

## 反例（禁止复刻）
- 一整段「为什么一杯冰咖啡、一本满是批注的论文、耳机里的爵士萨克斯……」印满上半屏。
- 人物端坐书桌、正脸微笑、像公司培训海报。
- 六张封面同一坐姿换背景；或六张全是夸张搞笑、没有一张运动/登顶帅气瞬间。
- **穿高定外套打网球 / 穿礼服进泳池**等场景服饰穿帮。
- 清单选题却做成「添加糖代谢机制概述」论文封面。

## 正例方向（勿照抄）
- 主句短：「会休息的人呢？」；只亮「会休息」。
- 网球发球定格：运动装、躯干打开、眼神盯球——可讲心肺负荷，也可讲「往高处打」的人生节奏。
- 爬山登顶远眺：冲锋衣被风掀起——可讲海拔/呼吸，也可讲「人生往高处行走」。
- **親子/出行清單**：flat lay「一口气 12 个」+「被问爆·无广」；或行李箱 POV +「必備清單·建議收藏」。
- **医学选题包（mk）**：纸纹底「谁写谁火」+「100个热门话题」；或「急救知识类」黄条+编号清单首页。
- **硬核网站（mk1）**：笔记本怼镜 MSD/3D 画面 +「3D讲清原理」。
- **漫画机制（mk3）**：左右分屏好细胞/黑化细胞 + 一句职场隐喻，不要显微切片墙。
- 人跳离椅子瞪大眼 + 空咖啡杯怼镜头（喜剧线仍可用，勿垄断全批）。
- 平台母语：小红书偏情绪短句；B站偏知识反差短句；视频号偏一句人话。

### 表情按选题定档（2026-08-01 修订：不是每张都夸张）
先判选题气质再定强度：  
- **平静生活向**（日常/居家/慢节奏）→ 自然神态：认真做事、低头笑、专注放松  
- **共鸣吐槽向**（小尴尬/明知不对还是做）→ 会心一笑、无奈摊手、心虚偷瞄  
- **反差反常识向**（数字拧巴/结果颠倒）→ 才用错愕张嘴、瞪大眼、坏笑  
- 吃喝/减脂：张口大吃、鼓腮、叉子怼嘴；「N件事」可竖指  
底线两头都守：大字很野时禁发呆望窗外；主句平和时禁满脸用力。  
- **好奇/价值钉**：先做N件事 / 又挖到宝了 / 刷到就是赚到 等开放环（举例，非唯一）  
- **A1 配色池轮换**（勿锁死单色）：暖黄块、品红侧栏、真相红、吸睛绿、知识黑金、走心红、水蜜桃、玫瑰金、天蓝/钴蓝、香槟琥珀；忌俗艳番茄红与荧光粉绿贴纸墙  


## 与出图
只用 `coverHeadline`（+可选极短副标）上屏；**禁止**把选题全文/长 hook 当封面正文；有人物就写清**表情+姿势+场景服饰且与文案同档**；清单向优先证据画面 + 大数字 + 结果钉；网感壳可叠侧栏/竖排/粉系双行，仍服务主句可读；禁变形花字墙与答案剧透。
