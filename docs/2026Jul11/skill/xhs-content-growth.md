# 爆款创作

本方法增量挂载，保留旧模板与原稿。“爆款”是创作目标，不承诺流量、收入或转化结果。

1. 使用用户背景简介与要求，先提出2–3个选题。平台可选小红书、抖音或两者；图文笔记和视频文案可同时选择。先选题，再确认内容；不要自动出图或发布。
2. 每个平台单独读取Growth样本，严格按窗口、日期类型、来源和场景匹配；缺少样本就说明，无依据不能编造热度或引用。采集数据不是本人账号曝光、点击、完播或成交。
3. 小红书：题目包含具体人群/场景和自然搜索词；正文用真实经历、有来源的步骤、可保存的清单，并兑现封面承诺。抖音：开头进入可见场景与问题，逐镜组织动作、口播、字幕、节奏与收尾；图文每页推进一个信息点。时长和页数服从用户要求，不把固定秒数或算法权重当规则。
4. 生成一个主选标题与三个不同切口备选，具体封面场景/构图/角色连续性方案，以及完整图文或分镜导演表。人物和场景与正文匹配，同组图片保持角色、服装与风格；避免纯文字墙。
5. 每篇一个主转化动作：关注需下一期价值，获客需具体站内承接，成交需真实产品、适用人群、交付与售后。不编造经历、评价、稀缺或收益，不强迫互动换正文答案。
6. 封面文字设计是稿件，实际封面图片必须由用户点选并确认费用后生成。正文生成不等于图片生成。文本GLM5.3FlashX，中文直送；图片Sunburst沿现有官方/EvoLink链路，同模型互为备用，结果未知不重复建单。
7. 发布后用本人后台同篇同窗口数据复盘，24小时与7天分别记录；一次只改标题、封面或开头中的一项。缺失分母不计算指标，点赞不冒充点击率。

资料依据：用户提供的Day2、运营策略、变现课Day1、账号诊断SWOT、运营知识地图。历史算法排序、认证费、流量门槛、固定时段与收益案例不作为现行事实。抖音适配采用场景开头、逐镜节奏、字幕与复盘方法，不采用角色模板中的固定权重或收益KPI。
