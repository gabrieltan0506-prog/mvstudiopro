# 旁白自然口語調整

用戶要求台詞像真人說話，不僅添加情緒標籤；用戶認可「捧起熱咖啡，手心也暖了起來」。

正式規劃入口 generateCodeMotionPlan 使用 GLM 5.3 FlashX 優先、DeepSeek V4.1 Flash 備援的既有 LLM 路線。這次調整同一個系統提示，不新增模型呼叫：具體動作與感受、完整自然搭配、符合人物關係的對白、先通讀潤色、長短句與留白；不靠快速語速塞超長文案。明確要求保留的用戶原話不擅改。

瑞芯探針的原六鏡是人工編排並經正式schema/compiler，不冒稱已實跑LLM規劃。已產音訊仍是原稿，本次未新增付費配音或影片生成。可採用的新旁白草稿：

- 0–5秒：這麼冷，還得趕著去上班。
- 5–10秒：捧起熱咖啡，手心也暖了起來。
- 10–15秒：留白，喝咖啡。
- 15–20秒：咦，怎麼一下就像春天了？
- 20–25秒：人暖和了，腳步也輕快了。
- 25–30秒：瑞芯咖啡，暖暖地開始這一天。

提示規則已改善；未實調LLM，所以不把fixture回歸當成新文案品質已驗收。
