# PR1697 影片消費與詞拍接入

本批修改基於 9a3c808649514b22141889982bea2c268569101a，在共享 pr1697 工作樹完成，子代理未 commit/push。保留原開發者程式與首次失敗紀錄，最終整合由主代理核對。

## 生產程式

- shared/codeMotionVideo.ts：4–5 秒已歸檔影片身份（gs URI、SHA-256、實際時長）與不重疊、對齊影格的時間軸。
- artMotion.ts、artMotionTask.ts、codeMotionVideoFrames.ts、artMotionRender.ts：正式受控入口接受影片；通用任務入口拒絕繞過工程；實際 bytes SHA/ffprobe/幀數核對；影片 FFmpeg 取幀，原生音軌靜音，最終使用既有原聲混音一次。
- CodeMotionPreview.tsx、composition.js、product-bridge.js：真正 HTMLVideo 依全局時間線 seek/play；與 Canvas 共用時鐘；影片之上採同一透明詞拍層，只有需要的影格才計算覆層。原聲由既有 AudioContext 播放。
- codeMotionTiming.ts（shared/server）、CodeMotionTimingPanel.tsx、codeMotion.ts/compiler、router analyzeTiming：保存可編輯詞語／短語秒窗、拍點、信心、語義動作。按 source trim/placement 編譯字幕與 pop/rise/slide/spin/fade，不平均分字。原生估計預設 needs-review，確認後用於正式導出。
- 分析從本人已存工程選用原音，核來源、版本、SHA、最多 30 秒秒窗；綁單一 timing slot，CAS manifest 在原生呼叫前占位。原始供應商回執先保存，成功可恢復、結果不確定與失敗不自動重呼叫。使用既有 Gemini 3.8 Flash 原生音訊，不安裝模型。

- 6 秒真正 renderer：靜態 PNG、移動幾何、4 秒實際 MP4、JUMP 詞拍、單一最終聲軌。144 幀（96 影片、48 代碼；14 幀透明詞拍覆層），真實畫面像素驗證字幕可見；原片 880Hz 被抑制。fixture-result.json、overlay-render-pass.log。
- 正式 bundled preview：真正 HTMLVideo + 官方引擎，驗 seek/play、靜音、排他結束點、透明 Canvas、層級與可見覆層。preview-engine-visible-pass.log。第一輪 mock 缺 byte-range、局部腳本路由錯誤均保留原始失敗。
