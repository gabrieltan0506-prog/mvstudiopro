# 已确认课程方法与数据读取改动

本批将人工审定的8项提案融入既有规则卡。方法版本为 `2026-10-14.6`，由初选与扩写服务编译到模型入参；图文和短视频按实际选择分别处理。课程只提供创作方法，不是当前平台规则或效果证据。

| 提案 | 实际规则与消费者 | 缺输入时的边界 |
| --- | --- | --- |
| A1 承诺、入口与交付一致 | `course-delivery`、`course-product-proof` → 正文与承接方案 | 不补造资源、价格、时效或入口 |
| A2 当前阶段与卡点 | `course-persona`、`course-demand` → 初选与扩写 | 原话、来源、想到的方法与实际尝试分别保留；缺依据标假设 |
| A3 分层复盘 | `course-measure`、复盘提示与现有实验枚举 → 方案视图 | 本人指标缺失时给采集计划；不将他人赞评当漏斗数据 |
| A4 真实选择与经历 | `course-scene-bridge` → 可选故事结构与正文 | 职业或愿意分享不等于已提供具体亲历，不编造顾客观察 |
| A5 证据画面、字体与排版 | `course-cover-layout`、`course-title-cover` → 封面及分页设计字段 | 不造业绩截图；制作说明不进入图文页读者正文；本次独立页按实际9:16画布；未渲染不称小屏已验收 |
| B1 口播重点与自然停顿 | `course-shot-plan` → 时间轴、剪辑备注与拍摄执行字段 | 不把制作标记念成台词，视线与布光仅为试拍建议 |
| B2 比例与变更检查 | 封面布局、拍摄规则 → 设计方案 | 改比例后复查裁切、遮挡、动画；不将静态检查当播放验收 |
| B3 数据尺度表达 | `course-product-proof` → 正文与证据方案 | 保留单位、对象、条件、来源，只做同维度可回算表示，不附加效果 |

数据读取沿真实采集库逐条扫描，查询缓存随原文件版本变化，候选内存、并发与等待队列有上限。现有草稿保留；空证据不显示参考区，说明字段不再在200/240字直接截断。关键词召回仍不等于语义匹配，模型须逐条复核标题与本轮用途。

验证分为代码与隔离回归、真实文本探针、正式页面验收和实际媒体质量。真实文本探针使用明确测试设定与已保存的双平台读取证据，不冒称用户本人经营经历；供应商原始响应和解析结果分别持久化。模型返回成功或结构审核通过不能代替全文审稿、实际图像、声音和试拍验收。未验证环节保持未验，不自动生成媒体或发送消息。

文本可行性检查拦截并列主动作、未提供容积/重量的参照类比，以及一一对应时间轴中明显超密度口播；明确汉字上限按本轮输入核对。未知时间格式和粗检通过都不能当实际时长验收，明确快嘴要求单独处理。
