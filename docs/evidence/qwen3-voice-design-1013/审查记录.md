正向：UI → protected canvasAudio → canvasVoiceDesign → canvasDialogueOperation → wavespeedVoice → prediction/GCS/结算 → 声线列表 → cue.voice → clone。
反向：对白音频 → 固定 voiceId → 本人成功设计原单 → GCS 原声样 → 原 prediction → 用户确认的设计输入。旧参考与默认音色维持原路由；设计样例不混入对白历史。

## 限制

当前锁是 cue/speakerId 在传入 blocks 中的锁，不是项目全 API 强制声线合同；独立 API 和视频模型参考链不能称全局强锁。只有正式采用且锁已保存才能依赖其恢复。同声样 clone 也不保证声音完全无漂移，必须听验。没有用测试绿或 PR 评论检查冒充线上验收。合并建议暂缓到隔离探针门禁闭合。
