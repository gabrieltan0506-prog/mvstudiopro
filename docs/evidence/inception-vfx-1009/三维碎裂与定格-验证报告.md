## 实际行为与界限

新增咖啡杯116块曲面杯壳/把手/底部与咖啡液滴；果摊216块，四组木箱、果皮/果肉、汁液、花瓣和纸页依次起爆。先爆发、后慢移、再定格，结束后继续。holdStartSec与holdDurationSec贯穿前端草稿、顾问、服务端合同、Blender和逐帧回执；手动画面轨迹在定格窗也暂停。

`prop_scene`选择本人已保存的三维人物动画：保持人物及相机原时间轴，只暂停道具。使用既有受鉴权queuePostProd(action=manhua_vfx)和Blender Python API，无新订阅/API密钥。场景身份、归属、源片段、SHA、源动画时长在入队及worker复核；不接受任意blend路径。人物静态/隐藏、源时窗不足或逐帧证据不一致会失败，不自动重做。该功能不会自动生成躲避碎片的表演。

`city_fold`是程序街区实体网格与真实铰链、透视相机；单独画面时窗替换并保留原声。它不重建电影街景。二维道具叠加不抠除原片物件、不提供人物前后遮挡；三维世界模式只计算已保存场景几何的遮挡。
