# 语音创作与一起看片使用指南

更新：2026-10-05。按用户指定归档到 Downloads/2026Oct04。

**交付状态：本批代码追加 PR #1662；管理者测试功能。未部署、尚未线上验收。以下为部署后的操作说明，不代表目前正式站已可使用。**

## 从哪里打开

- 漫剧工厂：打开某一部作品 → 创作顾问 →「语音讨论／一起看片」。
- 小说改编：打开当前改编工作区 →「语音讨论／一起看片」。
- 第一阶段仅管理员／supervisor可用。普通用户价格未定，不自动向所有用户开放。
- 点「开始讨论」先确认Google实际调用成本；只有点「开启麦克风」才申请录音权限。也可以只打字。

## 四种主要用法

| 场景 | 操作示例 | 结果与边界 |
| --- | --- | --- |
| 陪你看片 | 选择本机影片，或「读取本页播放器」选择当前成片；播放后点分享画面、分享影片声音。说“记录42秒配乐盖住对白”。 | 音画分别分享；画面最高约1FPS，附播放器时间。意见进入本作品本机修改清单，可点击定位、标为已处理、下载。未分享声音时不会假称听过配乐。 |
| 看分镜／资产讨论 | 分享一张分镜或资产参考图，说“比较人物站位，建议哪里适合白模或3DGS”。 | 结合实际分享图片与作品文字上下文讨论构图、灯光、人物关系、场景空间。不会因一句建议自动生成白模、3DGS或角色模型。 |
| 和创作顾问商量 | “保留权谋，让女主主动推动选择；请调用创作顾问推荐模板。” | Live可调用既有顾问，继续用原有创作服务与模板资料；顾问答案回到原入口，也回传语音对话。保留原有费用确认和候选稿采用流程。 |
| 用说话操作 | “打开第二集”“定位第二集第三镜”“把这条意见记到第二集第三镜”。 | 只操作真实存在的本作品集与镜头。镜头必须已有工作流分镜节点。可保存本机备注；不会偷偷改正式正文。小说页可切已生成集，尚无分镜的小说不能假装定位镜头。 |

## 还可以怎么用

- **检查时间因果**：选「推敲剧情与时间线」，口述“明晚酉时见面，失约却明早惩罚”的矛盾，请提出修订候选。
- **比较模板手法**：选「比较创作方法」，让顾问对比光线、场景、声音、表演、道具、节奏等特色；使用库里实际模板，不用题材套路代替学习内容。
- **白模／3DGS规划**：提供分镜图，讨论摄影机运动、遮挡、角色站位、哪些空间值得建模；得到建议后回到原有3D工具确认执行。
- **整理角色动机和对白**：连续口述你的修改方向，再交给原顾问生成候选；讨论本身不覆盖原稿。
- **审片待办**：把灯光、服装、配乐、对白、剪辑问题记到不同时间点，逐项处理后勾为已完成。

## 模型如何分工

你选择的是用途，不必选择模型版本：

- 口述构思、一起看片、白模场景讨论：普通 Gemini 3.8 Live，先 Vertex `us-central1`；连接建立失败才试 Gemini API，每路一次。
- 剧情时间线、模板方法比较：Extended Thinking，当前使用已验证可连通的 Gemini API，配置 HIGH，不设 MAX。
- 普通 Live 不发送 `thinkingConfig`。Extended 的 HIGH 是思考档位，不是保证不超支的硬上限。
- GLM／DeepSeek仍负责既有创作顾问服务。Live工具呼叫不会把整个工作流替换成Gemini；模型和计价沿用原入口。
- 连接成功后断线不自动重发对话，也不暗中重复付费。结束语音不取消已经提交的独立顾问任务，原入口可查询结果。

## 费用与确认

- 启动语音会话会产生Google实际成本。当前为管理者测试，正式语音积分价格未定。
- 既有漫剧顾问：每部作品5次免费，自动和手动建议共用；超出每次12积分，先确认。语音调用同一个入口，不另送一桶免费额度。
- 模板试写另算：每账户每日共3次，切换GLM／DeepSeek不会重置；每次试写一模板一集。
- 正式扩写每集6积分。小说改编当前沿用管理者实际成本确认，不冒充已经按正式用户价格结算。
- 语音工具不会自动发起影片、图片或白模渲染。媒体生成仍在原有入口确认。

## 修改清单、保存与恢复

- 对话和清单按账号／作品保存在本机浏览器；不是云端保存。
- 刷新可读回已保存记录；切换作品不会把前一作品意见写进后一作品。
- 时间点定位必须选回同一个影片。本机文件用名称、大小、修改时间识别；网页播放器地址变化后可能需要重新核对，不能自动定位到另一个影片。
- 下载「讨论记录」包含文字及清单；「清单原始备份」输出JSON，损坏记录也可原样取回。
- 旧清单无法解析时禁止用空清单覆盖。当前尚无清单JSON上传回填按钮，也没有跨设备同步；请保留导出文件。
- 「交给创作顾问讨论」只放入可编辑输入；正式改稿仍查看候选后采用。

## 音画输入的实际限制

- 本机影片在浏览器内播放，逐张发送抽样画面及选择分享的音轨，不会一次上传整个电影。
- 跨域网页播放器可能不能读取画面，界面会告知并建议选本机影片；不会将空白画面当作成功。
- 影片音轨共享依浏览器`captureStream`支持，Chrome需影片已经开始播放。若无可读音轨会明确提示；可继续单独用麦克风。
- 1FPS不适合逐帧动作、精确口型、闪烁或字幕时轴验收；这些仍需专门审片。
- 上下文展示框可核对本次送入内容；当前最多12000字符，超出会明确提示节选，模型没有读完整作品。
- 页面关闭、切作品、关闭面板或结束语音会关连接并停止本轮采集。空闲约90秒关闭；正在等待顾问工具结果不按这段空闲时间误杀。
