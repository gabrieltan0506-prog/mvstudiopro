# PR-A：带骨低模代理接入白模

状态：施工草稿，尚未实现，不可合并。

## 问题与目标
目前采用的带骨中模约230370顶点，10秒240帧超过1200万顶点帧预算。绑定阶段已有model-proxy.glb，但未上传或进入采用回执。接通代理作为白模来源，原模和中模保留原用途。2秒任务成功只证明现有链路可运行，不作为10秒或表演质量验收。

## 施工范围
- manhuaAutoRigRender/shared manhuaAutoRig：上传代理，核SHA、实际导出顶点数，补结果契约。
- manhuaAutoRigTask/manhua3dTask：采用时持久化完整代理来源，保持GCS镜像与恢复；白模可优先选代理，普通模型调用默认不变。存在损坏代理回执时明确拒绝，不静默降级。
- manhuaPrevisModels：入队前按全部角色、帧数、横竖屏投影次数计算预算；与Python口径对齐，不提高MAX_PROJECTION_WORK。
- manhuaPrevisRender：有界记录失败stderr，仅服务端可见；检查失败产物留存和临时媒体清理，永久JSON证据不删除。
- UI：准确说明白模模型来源、失败原因和请求编号。

## 验收
- 代理上传摘要不符拒绝，schema/采用/持久化往返不丢字段。
- 无代理的旧回执兼容；损坏或越权来源拒绝。
- 单人横屏10秒、多角色合计、竖屏三次投影预算边界。
- 测试、类型、完整diff审查；真实10秒白模另列线上验收，不以单测替代。
- 先调查既有代理是否可复用，不擅自重新绑骨、生成视频或启停rig机器。

不包含PR-B按需启停、PR-C四足、PR-E文戏动作库。后续代码集中追加本PR。
