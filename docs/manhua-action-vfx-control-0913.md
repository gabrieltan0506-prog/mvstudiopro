# 漫剧动作与特效控制层：本地验证与边界

本批为动作白模增加可编辑的持剑格挡、分段站位与转向、多人同时/错峰出水、爆点/烟团事件，以及可见人物/特效遮罩和相机深度层包。它提供剧情时序与空间控制，当前仍是预演，不能作为真实流体、体积烟火或复杂多人武打成片的验收。

## 数据与恢复链

现有白模编辑器 → 严格共享 schema → 原任务请求和队列 → 固定 Blender 脚本 → 实际逐帧报告 → 报告门禁 → scene/视频 → 可选分层脚本和完整层包 → 原单恢复/签名 → 预览与采用。

新增配置随草稿、历史和采用指南保留。旧剧本编译器遇到手工水轨、分段路线、特效或分层配置会拒绝覆盖，要求保留手工编辑。无新增配置时使用旧路径。计费、权限、请求幂等与原任务时限不变。

分层固定输出人物可见遮罩、特效可见遮罩及16位深度PNG，同一相机时间轴；黑色遮挡物参与深度遮挡。深度为相机裁切范围归一化距离，清单逐帧保存范围。带骨角色使用实际骨架名识别，附属角色沿父级识别。层包为固定路径 STORE ZIP，检查完整文件清单、尺寸、格式、字节数、SHA和解码；拒绝路径穿越、压缩炸弹、重复文件与跨任务路径。只对本人产物续签链接。

缺少已请求的层包时，提交回执与历史恢复不得加入可采用候选；重载的历史需先查询同一原任务预览再采用。层失败保留已有视频及原始/解析清单，不自动重跑。**层包恢复不等于人物动画缓存或只重做特效的局部重渲染。**
